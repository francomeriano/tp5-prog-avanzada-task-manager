# Trabajo Práctico: Task React (TP5) - Programación Avanzada

Manejador de tareas para proyectos de software desarrollado con React (Vite), Node.js (Express), PostgreSQL y Docker.

## Instrucciones para levantar el proyecto

1. **Clonar el repositorio:**
   ```bash
   git clone <https://github.com/francomeriano/tp5-prog-avanzada-task-manager.git>
   cd tp5-task-manager


2. Levantar los contenedores con Docker Compose:

docker compose up --build

# Acceso a los servicios:

Frontend (Aplicación React): http://localhost:3000

Backend (API REST): http://localhost:4000/api/tasks

Base de datos (PostgreSQL): Puerto externo 5433 (interno 5432).
